How the numbers are made value, budget, GP quoted, stated chance, PCA win rate, expected GP, attention labels

Value and budget are the Project Portal's Project Value and Budget as typed by the estimator; GP quoted = value − budget and GP % = GP quoted ÷ value. Stated chance is the portal's Probability of Close (blank = unscored, never 0 %). Expected GP (stated) = GP quoted × stated chance; Expected GP (PCA) = GP quoted × PCA's estimated win rate.

PCA's estimated win rate blends the historical hit rate of the estimator, the client, the division, the work type (from the project name), the size band, the market sector and the sales rep on {{ model.n|intcomma }} decided bids since 2019 (base rate {{ model.base|pct:1 }}), in log-odds, each factor weighted by how much evidence it has (12 decided bids = half weight) and the total damped by {{ model.damping }} because the factors overlap. Expand a row to see the factors behind its number.{% if model.cal %} Self-check on a time split (trained on {{ model.cal.train|intcomma }} bids decided before {{ model.cal.split|date:'M j, Y' }}, scored on {{ model.cal.test|intcomma }} decided since): Brier score {{ model.cal.brier }} vs {{ model.cal.brier_base }} for the base rate alone — lower is better. Predicted vs actual by bucket: {% for b in model.cal.buckets %}{{ b.bucket }} → {{ b.actual|pct:0 }} actual ({{ b.n }}){% if not forloop.last %}; {% endif %}{% endfor %}.{% endif %} It is a descriptive average, not a rating of anyone; the concealed estimator ratings live on the Ratings page.

Needs attention repeats the portal's own hygiene rules on each row: missing bidder, missing due date, no value, no budget, no submitted date, BOM needed, past due, unscored, untouched for 60 days.

Work type is read from the project name (cameras, access control, AV, network, IT services, box sale, service, RFP) — the portal has no type column; it falls back to the division's trade.
