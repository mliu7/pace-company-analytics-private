Reading this page definitions and caveats

Abandoned before this window: {{ abandoned.n|intcomma }} quotes ({{ abandoned.amt|money_k }}) created before {{ win.from|date:"M j, Y" }} are still "Open" in CNET and unconverted; CNET never expires a quote, so they are not in any total here. Widen the window to see them.
Statuses in this window: {% for s in statuses %}{{ s.status|default:"(blank)" }} → {{ s.outcome }} ({{ s.n|intcomma }}){% if not forloop.last %} · {% endif %}{% endfor %}.
Won is inferred: CNET has no structural quote→order link, so a quote is won when an order's internal note cites it ("QUOTE #…", exact) or the same customer ordered the same total (±2 %) within 60 days (a total match can point several near-identical quotes at one order, so won counts can double up); the method shows in the row. Win rate = won ÷ quotes created in the window (reps almost never mark quotes lost, so a "decided" rate would read ~100 %).
Totals are CNET quote totals (price incl. tax and S&H); GM is quoted price vs quoted cost — realized margin lives on the orders page once an order ships. Quotes with a total but no lines are lump sums whose detail was never entered line by line.
