What is verified on every run

  • Permissions audit — SL login must be exactly db_datareader with explicit DENY on INSERT/UPDATE/DELETE; PTT role must be non-superuser with no write grants and default_transaction_read_only=on. The run aborts otherwise. Last result: {% with runs.0 as r %}{% if r.permissions_audit.sl.ok and r.permissions_audit.ptt.ok %}both OK{% else %}see run {{ r.id }}{% endif %}{% endwith %}.
  • Checksum — Σ local PJTran copies by project × account = SL PJPTDROL actual amounts and units, to the cent.
  • Identity — every SL project matched to a PTT project by the exact key (no suffix stripping); unmatched keys become issues.
  • Hours — PTT onsite+OT+offsite hours vs SL labor-charge hours per project; >5 % differences are flagged, never silently reconciled.
  • Idempotence — transactions insert-once by natural key, time entries upsert by PTT id and keep soft-deletes, budgets are hash-diffed into a change log.
